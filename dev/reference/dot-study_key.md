# Key identifying the disease, parameter and study of an `<epiparameter>`

Key identifying the disease, parameter and study of an `<epiparameter>`

## Usage

``` r
.study_key(x, i)
```

## Arguments

- x:

  A `<multi_epiparameter>` object.

- i:

  The index of `x` in the `<multi_epiparameter>`, used to keep entries
  without an identifiable study from being grouped together.

## Value

A `character` string.
